# BookEase – Home Services Booking Interface

## 1. Project Overview

BookEase is a responsive frontend interface for a home services booking platform. It allows users to explore available home services, search and filter services, and submit a booking request through a simple and user-friendly interface.

This project was developed as part of the Stack & Scale Frontend Development Internship 2026.

## 2. Project Scope

The main purpose of this project is to demonstrate frontend development skills using HTML, CSS, and JavaScript.

The project includes:

- A responsive home page with a navigation bar and hero section.
- A home services listing section.
- Service search functionality using keywords.
- Category-based service filtering.
- A responsive mobile navigation menu.
- A booking form for entering customer details.
- Basic client-side form validation.
- A booking confirmation summary after successful form submission.

**Project Limitation:** This is a frontend-only project. It does not include a backend, database, payment system, or real appointment management.

## 3. Technologies Used

- HTML5 – Website structure and content.
- CSS3 – Styling, layout, and responsive design.
- JavaScript – Search, filtering, navigation, form validation, and booking confirmation.

## 4. Sample Data

The website uses sample home service information for demonstration purposes.

Example service categories include:

- Cleaning Services
- Plumbing Services
- Electrical Services
- AC Repair Services

Users can explore the sample services, search by keyword, and filter services by category.

The booking form collects sample customer information, including:

- Customer Name
- Phone Number
- Email Address
- Selected Service
- Preferred Date
- Preferred Time

All information is used only to demonstrate the frontend booking flow.

## 5. How to Run the Project

No additional software or package installation is required.

1. Download or clone this repository.
2. Open the project folder on your computer.
3. Locate the `index.html` file.
4. Open `index.html` in your web browser.
5. Explore the services and test the booking form.

## 6. Booking Simulation

Bookings on BookEase are simulated for demonstration purposes only.

When a user completes the booking form with valid information, JavaScript validates the input and displays a booking confirmation summary.

No actual appointment is created, and no customer information is stored in a backend or database.
